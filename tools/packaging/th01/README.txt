opentouhou th01
==============

This build runs the ZUNSOFT logo from Touhou 1. It exits after the intro.
Menus and gameplay are not included.

Put oth01 beside your original TOUHOU.DAT, or start it with:

    oth01 --data /path/to/th01

The original data is read only and is not included in this package.

Enter, Escape, Space, Z, X or Q skips the intro. A gamepad's south, east
or start button also skips it. F11 switches fullscreen.

The animation uses two 60 Hz shell ticks per update. The precise PC-98
refresh cadence has not been verified.
